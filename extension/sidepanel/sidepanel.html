零后端模式说明

零后端模式下插件无法直接读取服务器硬盘上的已装技能。你可以点下方按钮让当前 Antigravity 对话里的 Agent 列出全部已装技能，或在「连接」页切换为直连后端查看实时列表。

服务器直连配置（可选）

发给朋友时无需填写，默认「零后端模式」即可直接解析 MCP JSON、扫描 GitHub 技能仓库并填入 Antigravity 对话执行。若服务器已运行 ./start.sh，填写地址后可切换为双向实时管理。

零后端模式默认项目路径

当在零后端模式下选择「项目作用域」时默认填入的项目目录（留空则提示 Agent 使用当前工作区）。
