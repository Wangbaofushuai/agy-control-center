MCP 服务器

统一管理全局与各项目的 Model Context Protocol 服务器，支持 JSON 智能导入与精细配置。

配置新的或已有的 MCP 服务器，支持全局与项目级独立生效。

粘贴启动命令，或远程 Streamable HTTP 服务器的链接。

在本机运行。粘贴完整命令后会按每行一个参数拆分，也支持单行命令自动拆分。
